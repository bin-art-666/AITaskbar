# Halo

Windows 11 任务栏最左侧的圆环中转站。基于 AIEnter 的窗口、玻璃背板和任务栏接入，以及留白的中转站存储与拖放实现；两款应用可以同时运行。

## 使用

- 单击任务栏圆环打开／收起面板。拖向圆环停留 350 ms 展开，直接松手也可存入。
- 拖入成功后，圆环短暂显示一圈光效。失败时显示橙色缺口，点击圆环可查看失败详情。
- 圆环 SVG 画布贴紧图形外边界，中心镂空；任务栏入口不显示矩形底板或悬停方块，圆环跟随任务栏系统亮暗主题：亮色默认深灰 #505050，暗色默认浅灰 #E6E6E6，两套颜色独立设置。悬停时强调色沿圆环顺时针流动，亮色任务栏使用加深的圆环颜色、暗色使用白色，按下略微变暗。原生布局和透明点击区域保留，键盘焦点以圆形描边表示。
- 外观设置可调圆环大小 16–36 DIP、粗细 5–35%（线宽占外直径的比例），默认 30／17%。实时预览，保存后保留，取消或关闭设置还原；与文件图标大小分别设置。始终保留中心镂空，调整无需重启 Explorer。颜色支持选色器、#RRGGBB 输入和分别恢复两套默认颜色，另可调整流光开关、10–80% 圆周长度（默认 80%）及 50–200% 速度；关闭流光或系统动画时悬停使用对应主题的静态强调色。旧配置中的 RingColor 保留为暗色任务栏颜色，亮色自动补深灰。移开后流光约 150 ms 渐隐并停止计时器，待机不绘制动画。
- 面板以图标／缩略图及简短名称为主，右上角仅保留展开／缩起、置顶、收起三个 AIEnter 风格窗口按钮，没有标题文字或卡片操作按钮。收起不退出应用。
- 单击选择，Ctrl／Shift 多选，双击打开，拖出采用复制语义，记录保留。
- Ctrl+V 或空白右键“从剪贴板粘贴”主动接收文件、图片、文字和链接；输入框中的 Ctrl+V 仍用于编辑，不监听剪贴板变化。多行全为 HTTP/HTTPS 网址时先确认拆成独立链接、保留整段或取消，混合文字不自动拆分。
- 新建便笺可选择普通文字、Markdown、代码或网页摘录，可修改名称、代码语言和来源网址；网页摘录从拖入／复制的数据中提取基本段落、列表、标题、粗斜体与链接，来源仅在数据提供时保留，不请求网页或远程图片。Markdown 为本地基础语法预览，代码使用等宽显示，不执行代码。
- 选中一项后按空格或右键“快速预览”：支持本地图片、1 MB 内文本、PDF 翻页，以及系统解码器支持的音视频；媒体默认不播放，其他格式保留默认应用打开入口。预览原文件引用须明确选择。Markdown／代码单项拖出生成 .md／对应源码文件，复制内容仍提供原始文本；回收站和备份保留样式、语言和来源。
- .lnk／.url 显示快捷方式标识和本地系统图标，快捷方式仍按文件原样保存；读取图标不执行快捷方式、不查询网络目标，明确打开时才交给系统。

- 普通操作提示默认 4 秒后消失，失败和警告默认 8 秒后消失；设置中的“提示显示时长”可分别调整为 1–30 秒，并提供两种预览按钮。调整会重新计时，取消恢复已保存时长。复制／备份进行中持续显示，完成或失败后切换为限时结果。收起窗口清除旧提示；提示消失不会删除任务栏拖入的待重试内容，可在“桌面管理”中重试。
- 项目右键按类型显示操作：文件／文件夹可打开、复制、显示上级目录、复制路径、重命名；便笺可编辑与复制内容；链接可打开、复制与编辑。旧引用明确提供“打开引用”“保存为 Halo 副本”和“移除引用”，不直接重命名原件。多选仅显示批量复制及移到回收站，混合类型可复制路径与文本。双击保持打开／编辑行为。
- 空白处右键先清除选择，显示“全局操作”：新建、搜索、排序／整理空位、全选、回收站、外观及窗口选项；备份、恢复、重试拖入和全部移到回收站收进“桌面管理”，全部移除仍需确认。展开／缩起、置顶、收起使用右上角窗口按钮。右键已选项目保留整组选中，右键未选项目则切换到该项目；键盘菜单键使用同一套项目操作。
- 圆环右键提供「设置」和「退出 Halo」。左键打开或收起中转站，展开与置顶使用面板右上角按钮。退出会释放圆环占位，不停止共享 Windhawk。
- 设置窗口分为外观、任务栏圆环、提示、窗口与行为四页，沿用主面板背板。外观页显示可实时调整的网格示例，圆环页同时预览亮暗主题。底部固定取消和保存，有改动时可保存；排序及窗口行为在保存后应用。
- 主界面支持可留空的手动网格：拖到空格移动并保留原空位，拖到已有项目上单项交换；多选保持相对形状，碰撞或越界时拒绝，Esc 取消。拖动目标显示格子轮廓，上下及横向边缘自动滚动。紧凑／展开模式分别保存布局，首次复制当前布局；窗口变窄不重排，横向滚动查看，图标大小只改变格子尺寸。新项目优先填空位，空白右键 → 整理空位可排满；时间排序紧凑显示，切回手动恢复空位。内部调整不重复导入、不移动源文件，外部拖出保持复制并保留记录。
- 普通面板点击外部或 Esc 收起；两种模式的四边、四角均可调整宽高，拖动时保持对侧边缘不动，Esc 取消本次拖动。紧凑和展开模式分别记忆尺寸，展开模式另记位置。切换模式保留文件网格、选择和滚动状态；紧凑模式重新打开锚定左下角。独立窗口仅顶部空白可拖动；默认失焦自动收起，可在“窗口选项”关闭，置顶优先。置顶不阻止圆环再次点击收起。
- 外观包含图标大小（32–96 DIP）、水平间距和垂直间距（各 4–32 DIP，默认 12／8）、背板透明程度（0–80%）、背板模糊程度（0–100%）和圆角，设置显示当前数值。间距放在卡片外部，选中框使用紧凑的淡蓝填充与细边，保留两行文件名和原生键盘焦点提示。图标和间距实时预览，不重建卡片或改写手动行列及空位；取消、Esc 或点击外部恢复全部参数。保存后后台持久化，退出等待完成。两个背板参数作用于整个窗口，两种模式保持一致；仅对桌面做一次模糊。

支持文件、文件夹、图片、文字和 HTTP/HTTPS 链接。拖入的文件和文件夹完整复制到 Halo 文件库，平铺存放，同名自动编号。可在设置中查看和更改文件库位置。目录暂不可访问时可重试，恢复访问后继续使用原来的布局和回收站。旧记录标注“引用”，打开前可选择复制后打开或明确打开原文件，右键可转换并保留项目 ID 和位置。删除先进入 Halo 回收站，可选择恢复或确认永久删除。

在主面板按 Ctrl+F 搜索多级目录。结果显示相对路径，点「定位」打开所在文件夹并选中项目。勾选「搜索图片文字」后，Halo 使用系统已安装的识别语言在本机识别图片。收起面板会清除搜索。

默认最多 200 项，超出容量整批拒绝；文字和链接去重，副本文件独立保存，不按编辑后的内容合并。记录使用原子替换和 .bak 备份；损坏时恢复有效备份，未知版本或两份损坏时停止写入。任务栏拖入先持久化到本机队列，存储失败后转为 .json.retry 单独保留，由“桌面管理 → 重试未完成的拖入”手动处理，不随新拖入或启动反复重试；来源读取失败的数据包保留为 .failed，需重新拖入。同次处理的成功与失败分别报告，已提交副本后的队列清理异常不会报告为导入失败。快捷方式按 .lnk 文件原样复制，不解析目标。虚拟附件使用稳定批次路径防止重试重复。不会监听剪贴板或自动联网，只有手动点击复制才写入剪贴板。

## 构建与启动

GitHub Release 的 Windows x64 ZIP 包含 `Halo.exe`、预编译任务栏模组及 `Install.ps1`／`Uninstall.ps1`。解压到固定目录，在 PowerShell 中运行 `.\Install.ps1`。任务栏入口需要便携版 Windhawk（`AppDataPath=AppData`）。脚本可识别已运行的兼容实例；自定义或未运行的实例请传入 `-RuntimeRoot`，指向包含 `windhawk.exe` 的目录。卸载入口运行 `.\Uninstall.ps1`，必要时传入同一个 `-RuntimeRoot`。也可直接运行 `Halo.exe` 使用面板。

开发阶段复用 `D:\Develop\AIEnter` 内现有的 .NET 10、NuGet 离线包和 Windhawk 1.7.3 开发工具，不修改 AIEnter 的源码或模组配置。

```powershell
.\build.ps1
.\tools\taskbar\Start.ps1
.\tools\taskbar\Verify.ps1
.\tools\taskbar\Stop.ps1
```

应用在 dist/Halo.exe。也可以直接双击打开面板；真实任务栏圆环需要 Start.ps1 加载原生模组。`build.ps1 -AppOnly` 只构建应用，`-TaskbarOnly` 只构建模组。更新应用前先 Stop，仅停止 Halo。

Start 和 Stop 只操作共享 Windhawk 内的 halo-taskbar 模组，不重启 Explorer 或 Windhawk。默认不注册开机自启。应用数据默认保存在 `%LOCALAPPDATA%\Halo`；Start 可通过 `-DataDirectory` 传入独立目录。命名事件按数据目录隔离，可同时运行验收实例。

```powershell
.\dist\Halo.exe --toggle
.\dist\Halo.exe --settings
.\dist\Halo.exe --quit
.\dist\Halo.exe --verify-station --data-dir D:\Develop\Halo\.build\new-check
```

持续集成见 `.github/workflows/ci.yml`：每次推送/拉取请求在 Windows runner 上自包含构建应用并运行隔离原生验收，验收未通过则构建失败；任务栏模组依赖本地 Windhawk 开发工具链，仍在本地构建。

原生验收必须使用全新隔离目录，结果为目录中的 station-result.json。验证 Windows 数据包、容量／去重、持久化、恢复、附件回滚、原生网格和窗口位置，不读写系统剪贴板，不连接网站。可加 --preview 留下测试界面。跨软件实际拖放和系统版本兼容性需要额外实测。

## 边界与来源

任务栏入口在 TaskbarFrame/RootGrid 内添加真实布局列，不使用覆盖浮窗或托盘替代。背景继续铺满，系统应用组使用剩余布局空间，右侧 AIEnter 独立保留。卸载解除事件并恢复原有布局。未知布局或符号不可用时不插入。

任务栏依赖 Explorer 内部接口，当前已验证 Windows 11 build 26300、主任务栏、200% 缩放、居中应用组且小组件未显示的布局。多屏、自动隐藏、切换对齐、系统明暗切换及 Explorer 重启尚未全面验收。

窗口生命周期、背板、原生调整尺寸和任务栏拖放传输来自 AIEnter；StationStore、StationActions、StationTransfer 来自留白，并添加位图输入与独立应用接入。任务栏辅助代码上游为 Taskbar Folder Menus 2.1，许可见 ThirdParty/TaskbarIntegration-MIT.txt。
