# Halo 开发约定

- 独立 Windows 11 任务栏中转站；任务栏入口必须参与真实布局，不用覆盖浮窗或托盘替代。
- 任务栏入口位于最左侧，图标以 Assets/Halo.svg 为来源；保留圆环镂空。
- SVG 画布贴紧圆环外边界；任务栏按钮不绘制矩形底板或悬停方块，保留透明点按区域，反馈仅作用于圆环本身。
- 圆环大小和粗细在外观中独立调整，事件驱动同步任务栏并支持预览撤销；通信按 Halo 数据目录隔离，粗细限制须始终保留中心镂空。
- 圆环按任务栏系统主题使用两套自定义颜色：亮色默认 #505050、暗色默认 #E6E6E6；旧 RingColor 保留为暗色颜色。悬停流光亮色加深、暗色白色，仅改变圆环内部，支持 10–80% 圆周长度和独立速度；移开渐隐并停止计时器。关闭系统动画时使用静态强调色；预览取消恢复全部外观参数。
- 与 AIEnter 共存，应用、模组、事件、数据目录使用独立 Halo 标识。不得停止共享 Windhawk 或改写 AIEnter 模组配置。
- 主界面手动布局允许网格留空，空位不自动补齐；单项落到已有项目时交换，多选保持相对形状、碰撞或越界则拒绝。紧凑与展开布局独立持久化，首次从当前布局生成；时间排序不覆盖手动布局，新项目优先填空位，右键可整理空位。窗口加宽须开放新增列且正确识别落点，不能被保存的旧列数限制；窗口变窄通过滚动查看，图标大小只改变格子尺寸；内部调整与外部复制交付分开，拖动和取消不写位置，成功落下后提交。
- 当前阶段实现中转站存取闭环，不加入收藏夹、工作分组或其他留白功能。面板以内容网格为主，操作收进右键菜单。
- 右上角保留展开／缩起、置顶、收起三个 AIEnter 风格窗口按钮。紧凑和展开模式分别记忆宽高，四边四角均可拖动；整窗背板共用透明程度和模糊程度参数。
- 展开与 AIEnter 一致：独立窗口参与任务栏和 Alt+Tab，顶部空白使用原生标题拖动，首次居中、之后恢复自己的位置，失焦收起遵循窗口偏好（当前默认开启，置顶优先），拖离入口不自动收起；缩回恢复左下角面板。原生标题区域不得覆盖按钮或 XAML 缩放手柄。
- 默认不开机自启；卸载仅解除 Halo 事件和占位。兼容性须按实际环境验证后表述。

- 模式切换须防重入，先清理旧标题区域、取消收起动画，再按新布局恢复输入与标题区域；窗口样式回调不得触发整套外观重设。窗口设置合并后后台保存，退出等待保存完成。展开模式仅顶部标题空白区域可拖动窗口，排除三个按钮和缩放手柄；内容空白只取消选择，不捕获指针、不启动长按或原生拖窗。

- 第二桌面阶段：新拖入文件和文件夹先完整复制到 Halo 独立目录，后续编辑、重命名和删除仅针对副本；旧引用明确标识，转换保留 ID 和布局，打开原文件须用户明确选择。删除先入回收站，永久删除仅限校验过的独立副本目录；备份含文件、回收站和布局，恢复先自动备份，禁止路径穿越。搜索临时展开并随收起清除，不承诺加密或访问隔离。

- 文件卡片内层拖拽控件显式处理鼠标选择，避免与外层 GridView 重复切换；普通点击单选，Ctrl 增减、Shift 连选，已多选项目开始拖动前保留整组选中。图标和文字区域均须响应。

- 右键菜单按作用范围分开：空白处清除选择后显示全局操作，项目处按内容类型和单选／多选显示可用操作；右键已选项目保留多选，右键未选项目只选中该项。双击保持打开／编辑；窗口三个按钮不在全局菜单重复，全部移到回收站收进桌面管理并保留确认。

- 拖入结果按批次汇总，成功和失败分别说明；失败批次单独保留供手动重试，不随新拖入反复执行。副本提交后的队列清理失败不得报告为导入失败；导入快捷方式只复制其文件，不替换成目标文件。本地图标读取不得执行快捷方式或查询网络目标。

- 粘贴仅由 Ctrl+V 或明确菜单操作触发，不监听剪贴板。网页摘录只使用传入数据，基础 Markdown 用原生控件呈现，不执行 HTML／代码或自动加载远程资源。多行网址拆分必须确认，混合文字保留原文。文字样式、语言和来源随回收站、备份、恢复保留；旧便笺保持普通文字，文件快览不修改副本。
