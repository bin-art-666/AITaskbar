# AIEnter v2.0.0

- 任务栏图标升级为实时流动色球：固定圆形轮廓，内部粉、黄、紫、青色彩缓慢变形、融合；不是整张图片旋转或位移。
- 设置 → 任务栏新增色彩流动速度滑块与数值输入，范围 0–1800%，默认 200%，0 暂停。
- 速度支持实时预览、保存、撤销、恢复默认及配置导入导出，变化时保持动画连续。
- 系统关闭动画时保留原静态图标；模组卸载时停止并解绑动画计时器。
- 图标尺寸、时间右侧布局、左键开关窗口、右键设置、拖入文件和光晕机制沿用现有行为。

升级须同时替换主程序与 Windhawk 模组：导入并重新编译包内 Taskbar/aienter-taskbar-ai.wh.cpp。本版外观同步协议已更新，仅替换主程序不能控制旧模组的流速。

已通过程序和原生模组构建，以及实际任务栏速度预览、0/1800% 边界、撤销、图标尺寸和光晕集成检查。AI 网站附件上传仍受站点状态影响，尚未完成逐站验证。

适用于 Windows 11 x64，需 Microsoft WebView2 Runtime；任务栏入口需另装 Windhawk。程序包不包含用户登录资料或本机自启任务。
