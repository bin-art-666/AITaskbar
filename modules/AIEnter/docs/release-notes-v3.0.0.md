# AIEnter v3.0.0

## 新增截图与快捷复制

- 双击任务栏图标启动框选截图，遵循 Windows 双击时间和距离设置；单击延迟至双击判定结束，右键仍打开设置。
- 框选后立即保存 PNG，显示独立截图预览和 AI 操作栏；提供更多 AI、复制截图和关闭按钮。
- 支持预览内 Ctrl+C 复制图片；关闭预览、超时或选择 AI 均保留本地截图。
- 设置支持截图开关、保存目录、0–120 秒驻留时间（0 不自动关闭），默认 20 秒；悬停和更多菜单暂停倒计时。
- 选择 AI 后立即关闭截图预览，由 AI 窗口统一处理附件，避免置顶预览挡住确认框。

## 附件兼容与状态修复

- 截图与普通文件统一通过 StorageItems / ReceiveDrop 接收。
- GPT、豆包改走浏览器原生粘贴；DeepSeek 保留原附件路径。
- 原生粘贴期间在内存暂存剪贴板并恢复；期间用户复制新内容时不覆盖。
- 增加图片缩略图回执、迟到回执自动清理、超时保护与重复投递保护；未确认不再简单等同于投递失败。

## 安装与升级

普通用户推荐下载 **AIEnter-v3.0.0-Setup-win-x64.exe**。安装向导自动部署和配置任务栏组件，支持可选快捷方式、自启及卸载。首次安装需联网下载约 142 MiB 官方 Windhawk 组件，并校验 SHA256。安装包未进行商业代码签名。卸载时若 Explorer 锁定运行组件，会在下次注销并登录后自动清理该残留目录。

便携版更新时需同步更新 Windhawk 模组；安装版自动包含本版预编译模组。所有版本需 Windows 11 x64 和 Microsoft Edge WebView2 Runtime。

## 验证范围

已验证本地截图裁剪、PNG 保存、预览超时、移交即关闭、复制相关剪贴板恢复、新内容保护、附件与模式回归。真实 GPT/豆包的无上传拦截探测均收到可信 image/png 粘贴事件；该探测不代表服务端上传或解析完成。混合 DPI 多屏及所有 AI 网站完整上传仍未逐项验收。
