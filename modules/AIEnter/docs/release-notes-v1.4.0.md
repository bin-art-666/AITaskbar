# AIEnter v1.4.0

本版增加顶栏背板透明度调节，并将当前已保存的 UI 偏好固化为新安装与恢复默认配置。

- 设置 → 外观 → 顶栏背板可调节透明度，支持滑块和数值输入、实时预览；悬浮与展开模式共用设置。
- 滑块采用圆角轨道和更清晰的圆形滑块，保留键盘操作与高对比度支持。
- 默认面板为 388.5 × 816.5 DIP；背板圆角 20、透明度 20%；按钮圆角 16、高度 30、边距 4。
- 默认任务栏图标 25 DIP，光晕范围 6 DIP／强度 100%；网页圆角 28；默认快捷键 Alt+Space。
- 默认 AI 为 DeepSeek，顺序为 DeepSeek → ChatGPT → 豆包 → 小艺 → Gemini → Grok → Kimi；UI 风格使用默认预设。

下载 `AIEnter-v1.4.0-win-x64.zip`，完整解压后运行 `AIEnter.exe`。程序包包含 .NET／Windows App SDK 运行依赖；仍需 WebView2 Runtime。任务栏集成需另行安装 Windhawk 并导入 `aienter-taskbar-ai.wh.cpp`。安装步骤见包内 `README-使用说明.md`。

默认值只用于新安装和恢复全部默认，不覆盖已有用户设置。发行包不包含本机配置、窗口位置、聊天、账号资料或浏览器缓存，也不配置开机自启。
