# AIEnter v1.5.0

- 新增顶栏背板模糊度设置，支持 0–100% 滑块、数值输入、实时预览、保存和撤销。
- 透明度与模糊度独立调节；透明度 0% 为完全不透明，会遮住背景虚化。
- 修复背板容器未撑满、设置预览仅覆盖左侧的问题。
- AI 窗口的模糊改为取样桌面背景，沿用窗口圆角裁剪。

支持 Windows 11 x64；需 Microsoft WebView2 Runtime。时间右侧任务栏入口需另装 Windhawk 并导入附带模组，步骤见压缩包内使用说明。

构建与改动格式检查已通过。桌面背景虚化可能受 Windows 透明效果和电源策略影响；本版尚未完成不同 DPI 与显示器环境的视觉验证。
