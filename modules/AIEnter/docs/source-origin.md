# 来源与独立边界

AIEnter 于 2026-11-13 从用户的留白项目拆分，复用 AI 网站窗口、服务切换、网页圆角、文件暂存确认、窗口生命周期与玻璃视觉组件。

仅抽取所需源码，没有引用留白程序集或读取其数据目录。待办、中转站、时钟、二维码、摄像头、隐私设备控制和顶部栏均未包含。原来借用的中转站图标和拖入解析已抽成独立 AI 控件与数据传输组件。

应用程序集、命名空间、单实例事件、用户数据目录和任务栏扩展标识均改为 AIEnter。`.tools` 中的 SDK、NuGet 离线源、缓存、Windhawk 编译器与运行时为独立副本，不使用符号链接。

任务栏布局辅助代码改编自 Taskbar Folder Menus 2.1（sb4ssman 及贡献者），许可证见 [MIT 声明](../ThirdParty/TaskbarIntegration-MIT.txt)。Windhawk、.NET 和 Windows App SDK 保留各自许可证；这些依赖不改变上游源码的许可归属。
