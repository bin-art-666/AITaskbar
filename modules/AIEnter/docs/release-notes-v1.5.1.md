# AIEnter v1.5.1

- 修复原生拖入接管后未结束网页拖拽状态的问题，补发 dragleave/dragend，减少拖入遮罩残留。
- 网页就绪等待增加超时，未完成时保留待处理内容并提供重试。
- 改进多个附件入口的选择，优先匹配当前输入框附近的入口；支持豆包明确附件按钮的延迟入口。
- 豆包附件不再仅凭文件输入框写入返回就报告成功；核对网页新增可见附件，未确认时提供重新检查，避免重复投递。网页显示附件不代表服务器上传或解析完成。
- 将待处理区改为有高度限制的实色卡片，减少遮挡对话页面。
- 修复展开窗口四角缩放区域落在透明裁剪区的问题，沿可见圆弧识别对角缩放。

已通过独立构建、隔离网页的拖放/回执/模式切换及四边四角命中回归检查。豆包、DeepSeek 等真实网站的附件上传尚未完成逐站验证。

支持 Windows 11 x64，需 Microsoft WebView2 Runtime。时间右侧任务栏入口需安装 Windhawk 并导入附带模组。更新与配置步骤见程序包内使用说明。
