# AIEnter v1.2.0

本版重新整理设置窗口，并完善窗口与任务栏入口的日常操作。

- 设置改为五类导航与右侧卡片，底部固定显示保存状态和操作。
- 外观滑块增加精确数值输入和即时预览；光晕与网页圆角的关联选项按需显示。
- 设置改动跨分类保留为草稿；关闭或退出时可保存、放弃或继续编辑，恢复默认先预览再保存。
- 任务栏、窗口、AI 服务及备份恢复的现有设置功能按类别组织；保留键盘操作与系统高对比度配色。

下载 `AIEnter-v1.2.0-win-x64.zip`，完整解压后运行 `AIEnter.exe`。程序包包含 .NET／Windows App SDK 运行依赖；仍需 WebView2 Runtime。时间右侧任务栏集成需要另行安装 Windhawk，并导入 `aienter-taskbar-ai.wh.cpp`，配置 executable 为程序完整路径。使用步骤见包内 `README-使用说明.md`。

程序配置、网页登录资料和聊天数据不包含在发行包中。此版本不注册开机自启，也不包含已取消的自定义任务栏图标替换入口。任务栏扩展依赖 Explorer 内部布局，Windows 更新后可能需要适配。
