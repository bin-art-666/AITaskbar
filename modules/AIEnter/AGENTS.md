# AIEnter 开发约定

- 本项目是独立的 Windows 任务栏 AI 入口，开发、构建与运行均以本目录为根，不引用原留白目录。
- 修改 AI 窗口时复用现有公共视觉组件和窗口生命周期，不自动加入顶部栏或其他功能。
- 任务栏按钮必须参与 Explorer 的真实布局并预留位置，不替换为覆盖浮窗或托盘图标。
- 默认不开机自启。任务栏扩展只注入 Explorer；停用时解除事件并恢复布局。
- 按影响验证：AI 配置与导航测试、独立构建、单实例与退出、原生按钮布局；系统升级后重新检查任务栏兼容性。
- 同步直接相关文档；不得把未验证的兼容性描述为已完成。

- 任务栏顺序为时间日期 → AI 图标 → 显示桌面区域；悬浮面板每次打开锚定工作区右下角，右侧及底部间距 12 DIP，旧顶部偏移不参与定位。
- 静态图标沿用 Assets/source-icon.webp 原图透明通道，由 tools/build-icons.py 编码 PNG 和多尺寸 ICO，不加黑底。任务栏动态图标按用户要求实时绘制固定圆形内的流动色场，保留原配色；系统关闭动画时回退静态图标。

- 对话顶部保持单行服务与窗口操作，不恢复常驻标题／底部网址；关闭设置还原未保存的外观，调整不得重载网页。
- 光晕只表示对话窗口展开状态；仅设置、收起、正常和异常退出时均应熄灭，配置同步采用事件驱动。
