# AITaskbar

把 Halo、AIEnter 和 LumaBar 的源码整合为一个 Windows 11 x64 应用。三个模块编入同一个 `AITaskbar.exe`，共用设置窗口。LumaBar 的外观检测在同一进程的后台线程运行。

| 位置 | 模块 | 行为 |
| --- | --- | --- |
| 左端 | Halo | 从圆环拖入文件、图片、文字、链接，打开中转站后可预览或拖出 |
| 中间 | 应用区 | 固定应用、运行窗口和缩略图 |
| 最右端 | AIEnter | 打开或收起 AI 对话，拖入内容后交给当前 AI 的附件或草稿 |
| AITaskbar 预览栏 | LumaBar | 根据窗口或壁纸选择明暗，应用玻璃材质、对比度保护和鼠标光效 |

## 构建和运行

需要 Windows 11 x64 和 .NET 10 SDK。AI 对话需要系统的 WebView2 Runtime。可将便携 SDK 放在 `.tools\dotnet`，也可通过 `-DotnetPath` 指定 SDK。已有离线依赖时可放入 `.tools\feed` 并使用 `-Offline`。

```powershell
.\build.ps1
.\dist\AITaskbar.exe
```

设置窗口提供「任务栏设置」「Halo」「AIEnter」「应用中心」四个入口。「任务栏设置」下的「任务栏外观设置」包含 LumaBar 的玻璃、光效、明暗与应用规则，以及双栏对照、图标大小和运行标记颜色。「软件图标设置」管理各应用的图标样式。设置窗口底部的「退出 AITaskbar」会关闭集成模块并释放预览栏占用的空间。

拖动导航右边的竖线可调整分栏宽度。一级导航宽度在各页面共用，Halo、AIEnter 和应用中心分别记住自己的二级菜单宽度。双击竖线可恢复默认宽度。窗口较窄时，二级菜单会显示在内容区顶部的下拉框中。

「应用中心 → 图标设计」可显示或隐藏任务栏入口，也可调整四宫格大小、圆角和间距，以及白线长度和绕圈用时。点预览图标可查看展开时的边框动画。「界面设计」设置网格密度、亮色／暗色／与任务栏一致的背板，以及 A–Z 或手动排序。两个子页共用保存和取消按钮，各自的「恢复默认」只重置当前子页。

在任务栏中间应用区的四宫格上右键或左键单击，可打开应用中心。主页铺满任务栏上方的可用区域，支持搜索 Windows 应用列表、打开应用、查看共用的固定应用及滚轮横向翻页。再次点击图标或按 Esc 收起主页。手动排序模式下可拖动图标，或将图标拖到目标页的页点。右键主页空白处可进入应用中心设置或浏览本地程序。

集成版默认在 `%LOCALAPPDATA%\AITaskbar` 下为每个模块保存资料。本机切换时保留了原有 AIEnter 和 Halo 资料目录，集成版通过 `%LOCALAPPDATA%\AITaskbar\use-existing-profiles` 直接使用这些资料。LumaBar 设置已复制到集成版自己的子目录。

## 任务栏预览

本机登录后自动打开 AITaskbar，默认隐藏 Windows 原生任务栏。右键点击空白处可固定应用、打开设置、显示或隐藏系统任务栏、切换「覆盖窗口」，以及退出 AITaskbar。显示或隐藏的选择会自动保存。双栏对照时，AITaskbar 停靠在原生任务栏上方。启用覆盖后，AITaskbar 保持在原位并释放预留的工作区，最大化窗口可延伸到栏后。退出 AITaskbar 时，系统栏恢复到之前的状态。

构建后可运行 `wscript.exe .\tools\StartBackground.vbs` 重现登录启动。运行 `.\dist\AITaskbar.exe --compare` 可临时开启双栏对照。

「任务栏外观设置 → 任务栏高度」可在 10–60 DIP 间实时调整预览栏的高度与停靠空间。栏较矮时图标会按比例缩小。手动数值会自动保存，点「默认」可恢复到 50 DIP。

中间的应用区按应用显示图标。固定项在前，正在运行的非固定应用在后。运行应用放不下时，鼠标停在运行区滚动，每格切换一个图标，固定区保持原位。键盘聚焦某个图标后，可用左右方向键浏览所在区，包括空间不足时暂未显示的固定项。小点表示正在运行，短线表示当前前台应用。有一个窗口时单击切换或还原，有多个窗口时从图标上方的标题列表选择。右键可固定支持的桌面应用，以及画图、Windows 设置、ChatGPT 和 Windows 终端。也可通过「固定应用」选择桌面应用的 `.exe`。固定列表保存在 `%LOCALAPPDATA%\AITaskbar\preview-pins.json`。Halo 和 AIEnter 按钮可打开各自的面板，也可接收拖入内容，AIEnter 的内容进入附件或草稿流程。

预览栏左端的 Halo 圆环和最右端的 AIEnter 彩球沿用各自现有的外观设置。右键图标可直达 AITaskbar 设置中的对应页。Windows 原生任务栏保持系统外观。

AITaskbar 中的 Halo 用同一个 WinUI 浮层在缩起和展开间切换。缩起锚定左端圆环，展开可拖动顶栏空白处，四边四角可缩放。切换保留当前文件夹、选中项和滚动锚点，两种模式分别保存尺寸和手动网格。未置顶的展开面板被普通窗口盖住后，点圆环可召回，已经在前面时点圆环可收起。「展开后失焦自动收起」继续按保存的偏好工作。

Halo 整窗背板跟随任务栏明暗配色。在「Halo → 外观 → 窗口背板」可分别指定亮色和暗色底色，留空时跟随任务栏。透明度与模糊度沿用原设置。拖入文件继续复制到 Halo 资料库，拖出交付副本，面板内拖动按当前网格布局处理。

从 AITaskbar 打开的 AIEnter 使用与日历相同的 WinUI 浮层和实时玻璃合成。右上角切换按钮放大或缩小同一个面板，聊天网页保留当前草稿和滚动位置。顶部工具区实时跟随任务栏的亮暗配色，并根据背板与按钮的叠加颜色调整文字、图标和实际透明度。网页使用服务自身的主题、背景与圆角。打开或收起时，内容和玻璃一起移动、淡入或淡出。新配置的背板模糊默认设为 60，透明度保护只作用于绘制，用户保存的外观配置继续沿用。关闭 Windows 透明效果或开启高对比度时，背板使用实色。

在「设置 → AIEnter → 外观 → 顶栏背板」选择「自定义配色」，可分别设置亮色底色和暗色底色。各底色可独立重置为跟随任务栏，透明度与模糊度共用现有滑块。设置页可以切换预览主题，取消会恢复上次保存的配色。

展开后可拖四条边调整宽度或高度，拖四个角同时调整宽高，或拖顶栏空白处改变位置。松开保存，按 Esc 取消本次拖动。缩起沿用自己的尺寸，重新展开会恢复已保存的布局。展开位置保存在当前屏幕的工作区内，屏幕布局改变时会将面板限制在可见范围。

放大面板时可切到文件资源管理器，再把文件拖进聊天区。文件加入当前对话的附件，消息由用户确认后发送。展开时，取消固定后其他窗口可以覆盖面板，面板会保持打开。点击面板露出的部分或任务栏 AIEnter 图标可把它切回前面；面板在前面时点击任务栏图标会收起。固定后，面板保持在普通窗口上方。缩小面板后，点击面板外会收起，固定后则保持打开。

「任务栏外观设置」可直接调节背景透明度和模糊强度，动态效果会即时显示在预览栏。透明度为 0–100%，滑块旁显示实际透明度及自动对比度保护开关。选择「模糊玻璃」后可在 0–200 间调整强度，轻微模糊占更多滑块行程。点「取消外观更改」或关闭设置窗口可恢复已保存值，点「保存任务栏外观」可在下次启动时恢复。展开「场景设置」可单独编辑桌面、普通窗口和最大化场景，也可把当前材质、透明度和模糊值应用到所有场景。

预览栏中间的应用图标使用铺满格子的圆角底板。自带底板的图标保留原图比例和底色，透明标志默认使用白色底板，接近白色的标志使用深灰底板以保持辨识度。「任务栏外观设置 → 应用图标大小」统一调节图标和格子，默认 32 DIP，可在 24–36 DIP 之间即时调节并保存。在「任务栏设置 → 软件图标设置」中，可以为应用选择「使用原始图标」或「使用圆角图标」，更改会即时保存并应用。Windows 高对比度模式下使用原始图标。

在「任务栏外观设置 → 运行标记颜色」可为运行圆点和前台短条选色。选色时即时预览，点「应用颜色」保存，点「跟随系统」恢复 Windows 强调色。Windows 高对比度模式下使用系统前景色。

将鼠标停在正在运行的应用图标上约 400 毫秒，可在图标上方查看该应用的实时窗口缩略图，点击缩略图可激活对应窗口。窗口较多时可翻页。直接点击多窗口应用图标仍可打开原有的窗口标题列表。

可在预览栏内拖动固定应用，松手后将图标放到标记所示的前后位置。固定顺序即时保存，下次启动时恢复。

### 浏览器右键菜单

Chrome 和 Edge 各有「最近文件」和「最近关闭」，四项默认开启，可在「任务栏设置 → 图标设置」单独关闭。每个子菜单最多显示五条。「最近文件」读取 Windows 提供的本地文件记录，并用对应浏览器打开文件。

「最近关闭」通过浏览器扩展恢复具体标签。AITaskbar 随包提供扩展和本地主机，使用默认资料目录启动时会为当前 Windows 用户自动注册缺失的主机。首次使用时，在对应浏览器的扩展管理页开启开发者模式，选择「加载已解压的扩展」，加载安装目录下的 `BrowserCompanions/Chrome` 或 `BrowserCompanions/Edge`。扩展未连接、浏览器已退出或没有记录时，菜单会隐藏。AITaskbar 不另存浏览历史。

## 登录启动

当前用户登录后，计划任务「AITaskbar」延迟 20 秒运行 `tools\StartBackground.vbs`，启动 AITaskbar 并按保存的设置显示或隐藏系统任务栏。启动脚本将执行结果记到 `%LOCALAPPDATA%\AITaskbar\startup.log`。开始菜单中的 AITaskbar 快捷方式可打开设置窗口。

旧版曾通过便携 Windhawk 把 Halo 和 AIEnter 接入 Explorer。升级已有部署时，可对旧运行时执行 `tools\RegisterTaskbar.ps1 -RuntimeRoot .tools\windhawk -Disable`，重启后移除已加载的扩展。

## 源码

- `modules/AIEnter` 保存 AI 窗口、WebView2、截图、拖放和右侧按钮。
- `modules/Halo` 保存中转站、文件库、预览和左侧圆环。
- `modules/LumaBar` 保存外观检测、材质、光效和原生组件。整合版由根目录统一构建与更新。
